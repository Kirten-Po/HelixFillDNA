### 1. Кратко

HelixFillDNA **не собирает, не хранит и не передаёт разработчику** ваши
генетические или иные персональные данные. Программа работает локально
на вашем устройстве и обращается напрямую к сторонним публичным
сервисам импутации от вашего собственного имени (под вашей учётной
записью на этих сервисах) — Правообладатель не является посредником и
не имеет доступа к содержимому этих обращений.

### 2. Какие данные обрабатывает Программа и где они хранятся

2.1. **Исходный файл ДНК-теста** (экспорт FTDNA, MyHeritage или
готовый VCF), который вы указываете при запуске, обрабатывается
**только локально**, на вашем устройстве, в рабочей папке проекта
(`output/runs/<имя_запуска>/` и `donors/`). Программа не отправляет
этот файл разработчику и не сохраняет его копии за пределами вашего
устройства.

2.2. **Трафарет** (экспорт 23andMe, используемый как образец структуры
файла) обрабатывается аналогично — только локально.

2.3. Промежуточные и итоговые файлы конвертации (VCF, файлы для
загрузки на сервер импутации, готовый файл в формате 23andMe) остаются
на вашем устройстве и удаляются вами вручную по необходимости.

### 3. Передача данных третьим лицам

Единственная передача данных за пределы вашего устройства —
**загрузка обработанного файла на сервер импутации**, которую
инициируете и выполняете вы сами, под собственной учётной записью на
соответствующем сервисе:

3.1. **Michigan Imputation Server** (`imputationserver.sph.umich.edu`)
— используется для референсной панели **HRC r1.1 2016 (GRCh37/hg19)**.

3.2. **TOPMed Imputation Server / BioData Catalyst**
(`imputation.biodatacatalyst.nhlbi.nih.gov`) — используется для
референсной панели **TOPMed r3 (GRCh38/hg38)**.

Оба сервиса — независимые сторонние проекты (Michigan Imputation
Server — Мичиганский университет; TOPMed Imputation Server —
Национальный институт сердца, лёгких и крови США, NHLBI). У каждого —
собственная политика конфиденциальности и условия использования,
с которыми необходимо ознакомиться при регистрации на соответствующем
сайте. Правообладатель HelixFillDNA не контролирует обработку данных
на стороне этих сервисов и не несёт за неё ответственности (см. также
п. 6.2 EULA.md).

3.3. Какую бы панель вы ни выбрали, Программа обращается к серверу,
который её предоставляет: HRC — к Michigan Imputation Server, TOPMed —
к TOPMed Imputation Server / BioData Catalyst. Загрузка всегда
выполняется напрямую с вашего устройства, минуя разработчика.

### 4. Загрузка публичных референсных данных

Помимо загрузки *ваших* данных на сервер импутации (п. 3), Программа
также **скачивает** на ваше устройство открытые справочные наборы
данных — это одностороннее скачивание, не связанное с передачей ваших
данных:

4.1. **Референсный геном** (человеческий геном GRCh37 или GRCh38,
в зависимости от выбранной панели) — с публичного FTP-сервера проекта
1000 Genomes / EBI.

4.2. **Донорские образцы** популяции EUR — с того же FTP-сервера
проекта 1000 Genomes. Используются как вспомогательные образцы для
задания на сервере импутации (серверы требуют минимум 5 образцов) и
не относятся к вам лично.

4.3. **Chain-файлы для переноса координат** между сборками генома
(GRCh37 ↔ GRCh38, для панели TOPMed) — с публичного сервера UCSC
Genome Browser.

Ни один из этих трёх пунктов не предполагает отправку каких-либо
ваших данных — это исключительно скачивание общедоступных справочных
файлов.

### 5. Учётные данные (пароли, email)

5.1. Email, используемый вами для регистрации на сервере импутации
(Michigan Imputation Server или TOPMed Imputation Server), и пароль от
скачиваемого архива результатов обрабатываются Программой только
локально — для распаковки полученного архива результатов на вашем
устройстве. Они не передаются разработчику и никуда, кроме
соответствующего сервера импутации, не отправляются.
